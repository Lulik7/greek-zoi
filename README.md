# Слушаю греческий — говорю по-гречески

Сайт онлайн-школы греческого языка Зои Павловской: аудиоматериалы (песни и диалоги) с текстами
и переводом, разложенные по уровням Α1–Γ2 и по темам, с бесплатной частью и платной подпиской,
и с админкой, в которой всё содержимое меняется без разработчика.

Стек: **React 19 + TypeScript + MUI + React Router + Vite** на клиенте,
**Node + Express + SQLite** на сервере.

## Запуск

```bash
npm install
npm run dev      # поднимает сразу два процесса: API (4000) и сайт (5173)
npm run build    # сборка клиента в dist/
npm start        # боевой режим: один сервер отдаёт и API, и собранный сайт
```

Открывать: **http://localhost:5173**. База создаётся автоматически при первом запуске
и заполняется демо-материалами.

## База данных

SQLite, файл `server/data/school.db` — обычный файл, бэкап делается копированием.
Используется встроенный в Node модуль `node:sqlite`, поэтому ничего компилировать не нужно.
Загруженные аудиофайлы лежат в `server/uploads`. Оба каталога не попадают в git.

Таблицы: `levels`, `topics`, `tracks` (+ `track_levels`, `track_topics`, `lyrics`),
`users`, `settings`, `events`, `tokens` (ссылки из писем), `payments` (оплаты).
Весь доступ к данным собран в `server/db.js`, роуты — в `server/index.js`.

### Что сделано по-настоящему, а не «понарошку»

- **Пароли** хранятся только как bcrypt-хеш, на клиент не приходят никогда.
- **Сессия** — подписанный JWT в httpOnly-куке (JavaScript на странице её не видит).
- **Платные материалы не покидают сервер.** Без подписки в ответе API нет ни ссылки на
  аудио, ни текста песни — только пометка «закрыто». Аудио отдаётся через `/api/audio/:id`,
  и доступ проверяется на каждый запрос: без подписки приходит 403.
- **Оплата через Stripe** с вебхуком: подписку включает сервер после подтверждения платежа,
  повторная доставка события не продлевает подписку дважды, подделанная подпись отклоняется.
- **Подтверждение почты и восстановление пароля** — одноразовые ссылки из писем; в базе
  хранится только хеш токена, ссылка живёт 24 часа (подтверждение) и 1 час (сброс пароля).
- **Загрузка аудио** из админки идёт на сервер и получает постоянную ссылку.
- **Права**: всё под `/api/admin/*` доступно только роли «администратор».
- **HTTPS**: переадресация http→https, HSTS, `secure`-куки, запрет паролей по открытому http.

## Настройка перед запуском в интернете

Все секреты живут в файле `.env` рядом с `package.json` — скопируйте `.env.example`
и заполните. В git этот файл не попадает.

### Ключ подписи сессий (JWT_SECRET)

```bash
node -e "console.log(require('crypto').randomBytes(48).toString('base64url'))"
```

Полученную строку впишите в `JWT_SECRET`. С `NODE_ENV=production` сервер **не запустится**
без этой переменной — это защита от случайного выхода в интернет с общеизвестным ключом.
На своём компьютере ключ можно не задавать: он один раз сгенерируется в `server/data/jwt.key`.

Смена ключа разлогинивает всех — это нормально, если ключ утёк.

### Оплата (Stripe)

1. Зарегистрируйте аккаунт и возьмите ключ в **Developers → API keys**
   (`sk_test_…` для тестов, `sk_live_…` для боевого режима) → `STRIPE_SECRET_KEY`.
2. **Developers → Webhooks → Add endpoint**: адрес `https://ваш-домен/api/stripe/webhook`,
   события `checkout.session.completed` и `checkout.session.async_payment_succeeded`.
   Секрет `whsec_…` → `STRIPE_WEBHOOK_SECRET`.
3. Локально вебхук проверяется через Stripe CLI:
   `stripe listen --forward-to localhost:4000/api/stripe/webhook`.

Цены берутся из тарифов в админке — ничего заводить в панели Stripe не нужно, товар
создаётся на лету при каждой оплате. Пока ключи не заданы, оплата картой выключена:
на странице подписки вместо кнопки «Оформить» стоит «Написать для оплаты» с контактами
школы, а подписку включают вручную — админка, вкладка «Ученики», переключатель в строке.
Бесплатно доступ не открывается: запрос на оплату сервер в этом случае отклоняет.

Тарифы сейчас разовые: оплатил — открыт доступ на N дней. Если понадобится автопродление,
в `server/payments.js` меняется `mode: 'payment'` на `mode: 'subscription'`.

### Письма

Подойдёт любой SMTP: Yandex 360, Mail.ru для бизнеса, Resend, Postmark, Brevo, Gmail
с паролем приложения. Заполните `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `MAIL_FROM`.

Пока SMTP не настроен, письма не теряются: их текст печатается в консоль сервера, а ссылка
показывается прямо в окне регистрации/восстановления — так удобно проверять всё локально.

Письма уходят в трёх случаях: подтверждение почты при регистрации, восстановление пароля,
уведомление об оформленной подписке.

### HTTPS

Обычный вариант — сертификат выдаёт прокси (Caddy, Nginx, Railway, Render), а приложение
работает по http внутри сервера. Тогда достаточно `FORCE_HTTPS=1`: сервер сам переадресует
http→https, добавит HSTS и пометит куки `secure`.

Если сервер должен держать TLS сам, укажите `SSL_KEY_FILE` и `SSL_CERT_FILE` — тогда
приложение поднимется сразу как https-сервер.

Пример готового конфига Caddy (сертификат Let's Encrypt он получит сам):

```
greek-zoi.com {
    reverse_proxy localhost:4000
}
```

## Что уже работает

**Главная страница** — в порядке, который вы описали:
0. Самая верхняя полоса — греческая цитата с переводом (меняется в админке).
1. Первый блок: название в две строки — «СЛУШАЮ ГРЕЧЕСКИЙ» / «ГОВОРЮ ПО-ГРЕЧЕСКИ» —
   и под ним «Онлайн-школа греческого языка Зои Павловской». Фоном можно поставить
   фотографию: админка → «Главная и тарифы» → «Фотография в блоке с названием школы».
2. Поиск: понимает «уровень А1», «покупки», название песни, слово из греческого текста.
   Кириллическая «А», латинская «A» и греческая «Α» считаются одной и той же буквой.
3. Видео с инструкцией по использованию сайта.
4. Сменное видео («песня месяца») — меняется в админке в один клик.
5. Уровни: Α1, Α2, Β1, Β2, Γ1, Γ2 — кликабельные карточки со счётчиком материалов.
6. Темы: Любовь, Одежда, Покупки, Еда, Путешествия, Семья, Работа, Море — кликабельные.
7. Кнопка на полный список всех песен и диалогов.
8. Контакты — внизу (подвал).

**Каталог** (`/catalog`) — фильтры по уровню, теме и типу (песни / диалоги). Открытые
материалы проигрываются сразу, закрытые показывают окно «материал по подписке».

**Плеер** — под каждой записью кнопка «Показать текст». Текст идёт строками
«греческий → перевод», строка подсвечивается по ходу записи, по клику на строку запись
перематывается на это место. Если тайм-коды не проставлены, текст просто показывается целиком.

**Подписка** — три тарифа, страница `/subscribe`, личный кабинет со сроком действия.

**Админка** (`/admin`, только для роли «администратор») — пять вкладок:
- **Материалы** — добавить / изменить / удалить / дублировать запись; загрузка аудиофайла
  и короткого видео (до 200 МБ) прямо со своего компьютера — достаточно чего-то одного;
  переключатели «бесплатно» и «опубликован» прямо в таблице;
  редактор текста построчно + массовая вставка текста целиком в формате
  `0:12 | Καλημέρα | Доброе утро`.
- **Уровни и темы** — добавить, переименовать, переставить местами, удалить (удаление
  заблокировано, пока уровень или тема используется в материалах).
- **Главная и тарифы** — название, подзаголовок, контакты, обе ссылки на видео (с
  предпросмотром), цены и состав тарифов.
- **Ученики** — кто зарегистрировался, у кого активна подписка; подписку можно выдать вручную.
- **Статистика** — просмотры, запуски аудио, поисковые запросы, «упёрлись в замок».

## Телефон и планшет

Вёрстка адаптивная. На узких экранах: меню уезжает в выдвижную панель, поиск и кнопки
становятся во всю ширину, карточка материала перестраивается вертикально, а все таблицы
(полный список, материалы и ученики в админке) превращаются в списки карточек — ничего
не надо прокручивать вбок. Редактор материала на телефоне открывается на весь экран.

## Что нужно для боевого запуска

### 1. Оплата подписки — полностью автоматически, код готов

Схема: ученик нажимает «Оформить» → уходит на страницу Stripe → платит картой →
Stripe дёргает наш сервер (вебхук) → сервер включает подписку → ученик возвращается,
и всё открыто. Пароль он придумывает сам при регистрации, никто вручную ничего не выдаёт.

Осталось только вставить ключи в `.env` (см. раздел «Оплата (Stripe)» выше).

Что нужно знать про деньги:
- **Stripe** подходит, если у школы есть юрлицо/ИП в Греции или ЕС. Комиссия ~1,5 % + 0,25 €
  по картам ЕС. НДС и отчётность — на школе.
- **Paddle** берёт на себя НДС всех стран (merchant of record). Комиссия выше (~5 %), зато
  никакой отчётности. Если выберете его, менять придётся один файл — `server/payments.js`.
- Российские карты Visa/Mastercard в Stripe не пройдут — там нужен отдельный приём (ЮKassa
  или подобное) либо оплата переводом и выдача подписки вручную (кнопка в админке уже есть).

Ключевое правило, которое соблюдено в коде: подписку включает **сервер по вебхуку**, а не
браузер. Иначе доступ подделывается за минуту.

### 2. Хранение ~100 аудиофайлов — места хватает с большим запасом

100 файлов по 4–6 МБ — это 400–600 МБ. Даже 1000 файлов — около 5 ГБ, это копейки.

Рекомендую **Cloudflare R2** или **Backblaze B2**: хранение ~$0,015 за ГБ в месяц, у R2
бесплатная отдача трафика. Для 100 файлов выйдет меньше $1 в месяц. Файлы отдаются по
подписанным ссылкам с коротким сроком жизни — чужой человек не сможет скачать платный трек,
даже если получит адрес.

Про SoundCloud: как хранилище он рабочий вариант, но платные треки там придётся держать
приватными и вставлять через их плеер, а это чужой плеер, чужой дизайн и невозможность
синхронизировать нашу подсветку текста. Свои mp3 в R2 дешевле, надёжнее и полностью наши.

Сейчас файлы можно загружать прямо из админки — они лежат в `server/uploads` и раздаются
сервером с проверкой подписки. Поле «Ссылка на аудио» при этом принимает и внешний адрес,
так что переезд на R2 или SoundCloud ничего не сломает.

### 3. Как передать материалы

Проще всего — **Google Drive**: сложить всё в одну папку и дать доступ на скачивание. WeTransfer
тоже подойдёт, но ссылки живут 7 дней. Что нужно вместе с файлами:

- аудио с понятными именами: `A1_pokupki_v-supermarkete.mp3`;
- тексты — обычная таблица (Excel/Google Sheets): название по-гречески, перевод названия,
  уровень, тема, тип (песня/диалог), бесплатно ли, текст с переводом. Один раз залью всё
  скриптом, дальше вы добавляете новые записи через админку сами.

Тайм-коды для подсветки строк проставлять не обязательно — без них текст просто показывается
целиком. Если захотите подсветку, их можно расставить в админке за пару минут на запись.

### 4. Статистика посещений

Внутренний счётчик уже есть (вкладка «Статистика»): что слушают, что ищут, на каких закрытых
материалах люди упираются в замок — это, кстати, лучший источник идей, что открыть бесплатно.
Дополнительно на боевом сайте подключается **Plausible** или **Umami** (не требуют баннера
про cookies, ~$9/мес) либо бесплатная **Google Analytics 4** — они дают источники трафика,
города, устройства и воронку «зашёл → послушал → оплатил».

### 5. Ориентировочная стоимость эксплуатации

| Статья | В месяц |
|---|---|
| Хостинг сайта и API (Railway / Render / VPS) | 0–7 € |
| Хранилище аудио (Cloudflare R2) | ~1 € |
| Домен | ~1 € |
| Аналитика | 0–9 € |
| Комиссия платёжной системы | % с оплат |

База SQLite живёт на том же сервере и отдельных денег не стоит. Если школа вырастет до
тысяч учеников, база переносится на PostgreSQL — меняется только `server/db.js`.

### 6. Порядок выхода в интернет

1. Купить домен и поднять сервер (Railway, Render, Hetzner + Caddy — любой вариант).
2. Скопировать `.env.example` в `.env`, заполнить `JWT_SECRET`, `PUBLIC_URL`, SMTP и Stripe.
3. `npm ci && npm run build && npm start` — один процесс отдаёт и сайт, и API.
4. Прописать вебхук в панели Stripe и проверить тестовой картой `4242 4242 4242 4242`.
5. Настроить резервное копирование `server/data/` и `server/uploads/` (обычное копирование
   файлов по расписанию).

Что осталось за рамками и делается по желанию:
- перевод аудио во внешнее хранилище с подписанными ссылками (сейчас файлы раздаёт сам
  сервер — для сотни записей этого достаточно);
- письма о скором окончании подписки и автопродление;
- перенос базы на PostgreSQL, если школа вырастет до тысяч учеников.

## Структура проекта

```
server/
  index.js               API: аккаунты, доступ к аудио, оплата, админские операции
  config.js              переменные окружения, ключ подписи сессий, настройки HTTPS
  db.js                  SQLite: схема и все запросы к базе
  payments.js            Stripe: создание оплаты и обработка вебхука
  mailer.js              письма: подтверждение почты, сброс пароля, оформление подписки
  seed.js                демо-наполнение (10 материалов, 6 уровней, 8 тем)
  data/school.db         сама база (создаётся при первом запуске)
  uploads/               загруженные аудиофайлы

src/
  api/client.ts          единственная точка обращения к серверу
  store/AppContext.tsx   глобальное состояние: данные, текущий пользователь, действия
  lib/search.ts          разбор поискового запроса и фильтрация
  components/            шапка, подвал, поиск, видеоблок, карточка трека, окно входа
  pages/                 главная, каталог, полный список, подписка, кабинет, смена пароля
  pages/admin/           админка: материалы, уровни и темы, настройки, ученики, статистика
```
